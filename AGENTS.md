# Project guidance

When creating or changing the project's interface, read and follow `design/DESIGN-STANDARD.md`. It records the user-approved Abyssal Bloom palette and Manrope / Inter typography scale, with the original references in `design/reference/`.

Reuse the bundled fonts in `ten-years/dist/fonts/` and the scoped theme variables in `ten-years/dist/style.css`. Preserve existing data semantics and timeline controls when making visual changes. Explicit later user instructions take precedence over this guidance.
